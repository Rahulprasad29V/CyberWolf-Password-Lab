# CyberWolf Password Lab

A client-side password security toolkit built with plain HTML, CSS, and JavaScript.

## Features
- Cryptographically secure password generation with Web Crypto API
- Password strength and entropy analysis
- Passphrase generation
- Bulk generation with TXT/CSV export
- Password policy builder
- Responsive CyberWolf dark UI
- No backend and no password storage

## Run
Open `index.html` in a modern browser.

For best browser security behavior, serve it over localhost or HTTPS when deploying.

## Security notes
Passwords are processed locally in the browser. The project does not include a backend or database.
